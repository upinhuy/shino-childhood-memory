One sentence, at most 280 characters, that makes the judge feel nostalgic for a childhood memory — entered in the [make.fun bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363).

> At dusk my grandmother would lift the lid off the rice pot and the steam would fog my glasses, and for one warm minute the whole world was just her kitchen, the radio humming low, and nobody asking me to grow up yet.

The memory is a single warm minute from a childhood evening: steam from grandmother's rice pot fogging a pair of glasses, a radio humming low in the kitchen, and nobody asking the child to grow up yet. The sentence is 216 characters — one sentence, inside the 1–280 character gate.

`main.py` validates the sentence (exactly one sentence, 1–280 characters counted as Unicode code points) and writes it to `/output/entry.txt` for the house judge. Run it locally with:

```sh
python3 main.py
```
